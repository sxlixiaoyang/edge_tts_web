Edge TTS Web API - Free Text-to-Speech API, no registration required

Quick Start

No API key needed! Just send a POST request to synthesize speech:

curl -X POST YOUR_DOMAIN/synthesize \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello World", "voice": "en-US-JennyNeural", "rate": "+0%"}'

Synthesize Speech

Convert text to speech and get a download link.

POST /synthesize
Request Headers
HeaderValue
Content-Typeapplication/json
Request Body
ParameterTypeRequiredDescription
text string Yes Text to convert to speech
voice string No Voice name (default: zh-CN-XiaoxiaoNeural). Get from /api/voices
rate string No Speech rate: "-100%" to "+100%" (default: "+0%")
Request Example
{
  "text": "Hello, this is a test.",
  "voice": "en-US-JennyNeural",
  "rate": "+0%"
}
Success Response 200
{
  "message": "success",
  "download_link": "/mp3/abc123def456.mp3"
}
Error Response 400/500
{
  "message": "error",
  "error": "文本不能为空"
}

Download Audio

Download a generated MP3 file using the link from synthesize response.

GET /mp3/{filename}
Parameters
ParameterTypeDescription
filename string MP3 filename (from synthesize response)
Usage

Simply open the download_link from the synthesize response in your browser, or use it programmatically:

import requests

response = requests.post(
    "https://your-domain.com/synthesize",
    json={
        "text": "Hello World",
        "voice": "en-US-JennyNeural"
    }
)
data = response.json()
audio_url = f"https://your-domain.com{data['download_link']}"

# Download the file
audio = requests.get(audio_url)
with open("output.mp3", "wb") as f:
    f.write(audio.content)

Notes

  • No API key required — This service is completely free, powered by Microsoft Edge's online TTS.
  • No rate limit — But please use reasonably and avoid abuse.
  • Text length — Recommended to keep text under 5000 characters per request for best results.
  • Audio format — Output is MP3 format.
  • File retention — Generated files are stored locally on the server. No cloud storage.
  • Base URL — Replace YOUR_DOMAIN with your actual deployment domain (e.g., https://your-domain.com).
